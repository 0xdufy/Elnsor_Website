# AGENTS_V2.md — Al Nesour Feeds Website Redesign Brief

## 0) Mission

Redesign the current Al Nesour Feeds website from the ground up.

The current version is too editorial, too cautious in tone, and visually less convincing because some imagery feels obviously generated. The redesigned site must feel:

- smoother
- clearer
- more commercial
- more realistic
- more trustworthy
- more relevant to the Egyptian feed-supply market
- easier to contact
- more visually attractive

This is a **full redesign**, not a minor refresh.

The final site must be implemented with:

- HTML
- CSS
- Vanilla JavaScript

No frontend framework.

# 2) Redesign diagnosis

The current website has these problems and the redesign must fix them:

## Problem A — the copy is too defensive
The current copy sounds like an internal compliance brief in several places.  
Public copy must sound commercial and confident, not hesitant.

Bad tone examples:
- explaining too much what the site is *not*
- discussing lack of automation
- repeating what is not confirmed
- sounding like a spec sheet instead of a real company site

## Problem B — the website is longer than necessary
The homepage should be more focused and easier to scan.  
Sections should not feel repetitive.

## Problem C — imagery feels artificial
The owner does not have real photography.
AI imagery is allowed, but it must look **highly realistic and documentary**, not synthetic or glossy.

## Problem D — current visual direction is too editorial
The redesign must shift toward:
**modern commercial feed-supply website**
instead of:
**editorial structured corporate showcase**
